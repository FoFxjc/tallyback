Accountability after delegation

Coordination ≠ accountability

Subagents solve delegation. Agent teams solve coordination. Tallyback starts where coordination stops.

02

The responsibility survives

Sessions end. Models change. Worktrees disappear. The Task remains.

The stable identity in Tallyback is the Task. Agents, sessions, models and worktrees are replaceable executors underneath it.

03

Ledger ≠ reality

A decision can be recorded without pretending Git already agrees.

LEDGER REALITY tallyback view
Task A LAND settled
Task B LAND settled

View answers what was declared, attempted, claimed, verified and settled. It does not read live Git.

≠
LIVE GIT REALITY tallyback land
Task Agit_ready Task Bgit_ready Conflict groupapp/main.py
merge Task A outside Tallyback
↓
Task Agit_integrated Task Bgit_behind

Land reports the new Git reality. It does not merge, rebase, push, or silently promote anything.

Verdict ≠ acceptance ≠ landing authorization ≠ actual Git integration
